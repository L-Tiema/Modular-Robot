# Modular Robot

NUSRI Suzhou FYP SP18  
**Reconfigurable Wheeled Robot with Modular Edge-AI Capabilities**

面向室内环境的多移动单元可重构机器人。项目以常规差速轮式底盘完成核心交付，并在核心系统通过后扩展主动轮腿底盘。

## 项目目标

- 构建可靠的轮式移动单元，支持电机闭环、电源管理和安全保护。
- 定义统一的机械、供电和通信接口，使功能模块可以拆装和复用。
- 实现两个移动单元的机械连接与协调控制。
- 使用 LiDAR 与深度相机完成环境建图和障碍感知。
- 部署轻量 Edge-AI 目标检测，并实现指定人员跟随。
- 对定位、检测、跟随、通信和组合运动进行定量评价。

## 技术路线

### 第一阶段：常规轮式核心系统

每个移动单元采用两轮差速结构，包含编码器电机、驱动器、电池、UNO Q 和标准模块接口。两个单元可独立运行，也可人工连接后作为一个平台控制。

### 第二阶段：主动轮腿扩展

核心系统完成并通过阶段检查后，开发可替换的主动轮腿移动单元，复用同一套上层感知与 AI 模块，比较两种底盘的地形适应性、运行平稳性、跟随误差和能耗。

轮腿平衡与跳跃单独验证，不作为核心系统验收的前置条件。

## 控制架构

```text
LiDAR / Camera / IMU
         |
         v
UNO Q Linux (ROS 2)
建图、检测、跟随、单元协调
         |
         v
Bridge / RPC
         |
         v
STM32U585 MCU
编码器采样、轮速闭环、看门狗
         |
         v
电机驱动器 -> 电机
```

电机功率不经过开发板 GPIO。上电默认不使能，急停与失联保护由独立硬件和 MCU 本地逻辑保证。

## 开发环境

- Arduino App Lab 0.10.0
- Arduino UNO Q 4GB
- ROS 2
- C / C++ / Python
- GitHub Desktop 或 Git CLI
- VS Code

ROS 2 发行版、容器镜像和传感器驱动版本将在实物验证后固定。

## 建议目录

后续代码和硬件资料按以下结构组织：

```text
firmware/          MCU 固件与通信程序
ros2_ws/src/       ROS 2 功能包
hardware/          CAD、接线图、BOM
tests/             标定、性能与故障测试记录
docs/              设计说明和实验记录
outputs/           报告、计划与演示材料
```

## 协作约定

- 新功能使用 `feature/<名称>` 分支开发。
- 提交前检查 `git status`，不要提交构建目录、依赖或传感器原始数据。
- 合并前至少完成一次双人联调或代码检查。
- 所有性能结论必须附测试条件、日志或数据记录。
